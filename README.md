# Сундук или Монстр

Пошаговая текстовая игра-рогалик на C#. Форк учебного проекта с доработками.

## Об игре

Игрок путешествует по миру, и на каждом ходу ему случайно выпадает **сундук** или **монстр**.

- **Сундук** даёт оружие, броню или лечебное зелье. Оружие определяет урон, броня — защиту.
- **Монстр** начинает бой. Можно атаковать или защищаться; при защите есть шанс до 40% полностью уклониться.
- Каждый 10-й ход — бой с **боссом**.

### Противники

| Обычные | Боссы |
|---------|-------|
| Гоблин (шанс крита) | Орк |

| Маг (может заморозить) | Архимаг |
| Shpilka | |

## Архитектура

- `Model/` — сущности: `BaseEntity`, `Player`, враги, предметы, `DamageInfo`, статусы;
- `Interface/` — интерфейсы `IGame`, `IWeapon`, `IArmor`, `IBaseItem`;
- `Factory/` — `EnemyFactory` и `ItemFactory` для случайной генерации;
- `Program.cs` — меню и игровой цикл.

## Запуск

Требуется .NET SDK.

```bash
dotnet run --project ChestOrMonster
```
