Практическая работа по ИСПРО
Тема: совместная разработка в GitHub, ветки и Pull Request

В проект добавлены:
- новый обычный враг «Берсерк» с уникальными характеристиками и особенностью «Ярость»;
- лук как отдельный тип оружия с характеристикой «Точность»;
- два варианта лука в фабрике предметов;
- замена текущего оружия игрока при выборе лука или оружия ближнего боя;
- вывод сообщения о промахе;
- отдельный консольный проект с четырьмя автоматическими проверками.

Сборка:
dotnet build ChestOrMonster.sln

Проверки:
dotnet run --project ChestOrMonster.Tests\ChestOrMonster.Tests.csproj

Локальная ветка: feature/bow-and-berserker

Предлагаемое название Pull Request:
Добавлен новый враг «Берсерк» и новый тип снаряжения «Лук»

Описание Pull Request:
Добавлен класс Berserker с характеристиками здоровья, атаки и защиты. Его особенность
«Ярость» удваивает урон, когда здоровье снижается до половины. Добавлен класс Bow
с характеристикой Accuracy, которая определяет шанс попадания. Фабрика предметов
создаёт обычное оружие или один из двух луков. Игрок хранит только одно текущее
оружие, поэтому лук и оружие ближнего боя заменяют друг друга. Добавлены проверки
попадания, промаха, замены оружия и усиленной атаки Берсерка.
